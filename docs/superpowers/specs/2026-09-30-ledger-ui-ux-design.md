# 记账应用整体交互与界面改进

用户已批准将 2026-09-30 的整体 UI/UX 评审建议一起实施。

## 目标

提升快速记录、补记历史消费、查看流水、理解分摊和统计的效率。使用现有 Flutter / Material 组件、Riverpod、统一主题，保持现有离线、共享账本、同步与 AI 草稿能力。

## 记账与复核

- 新建、编辑、AI 复核复用日期、币种和付款方式控件。日期默认今天，可以补记历史日期；编辑保留原时间。
- 单一币种展示静态信息，少量选项直接展示，多选项使用可搜索面板。
- 谁付款、谁承担、收入分配对象明确区分；选择变化即时显示付款与等额分摊摘要。
- 非法金额、未选参与人、未知分类和未知姓名在对应区域持续提示，并定位第一个错误；金额必须有限且大于零。
- 保存成功采用轻量通知，提供撤销及查看路径，保持连续记账。撤销通过现有删除流程同步，失败明确反馈。
- 空记账页直接创建账本，成功后回到记账并选择新账本。显示最近三笔和查看流水入口。

## 流水与统计

- 流水搜索及筛选置于容易找到的位置；无结果与无数据正确区分，提供清除筛选。
- 流水按日期分组，显示当日收入/支出，跨年日期包含年份。
- 统计支持具体月份和自定义包含起止日的日期范围；点分类查看相同范围/类型的流水，返回保留上下文。
- 总额、币种、时间范围清楚；增加上期比较及日趋势；上期为零时明确说明，不显示无穷百分比。

## 视觉与布局

- 全局字号、字重、间距、卡片与弹层规范统一，正文常规字重、标题适度加粗，关键金额突出。
- 弹层仅一个拖拽条；人民币固定汇率用说明代替输入框；创建操作固定底部。
- 账本名称优先显示，编辑/同步/分享/排序等次要操作整合，内部编号在详情中查看。
- 窄窗口保留底部导航；宽窗口采用侧边 NavigationRail，内容限定宽度，统计与流水适当使用多列。
- 尊重减少动态效果设置，保证触控、键盘及选择状态语义。

## 验收

验证补记及编辑日期、金额/人员错误定位、分摊、保存撤销、首次创建、最近流水、跨年分组、统计月份/自定义范围/分类返回/零基线比较以及窄屏和宽屏。全套 Flutter 测试、静态分析及 Web 构建通过后合并 master 并启动本地预览。
