# 加入邀请的跨端契约

`POST /api/invites/{code}/join` 继续返回旧版邀请字段，同时新增以下快照字段：

- `invite`：完整的旧版邀请对象，用于兼容旧客户端。
- `ledger`：账本 UUID、版本、当前用户角色和成员摘要。
- `member`：当前用户在账本中的成员 UUID、角色、状态和版本。
- `person`：当前用户在该账本中的关联参与人 UUID、姓名、头像和版本。

Flutter 收到完整快照后会在本地恢复/创建云账本和关联参与人。已有本地 UUID（通过 `syncedRemoteUuid` 或账本参与人列表匹配）会复用；待同步的本地编辑不会被云端加入快照覆盖。旧版扁平响应仍只执行账本访问恢复，保证灰度期间的兼容性。

每次加入请求使用新的 UUID 作为 `Idempotency-Key`，重试由服务端幂等记录保证不会重复消耗邀请码。请求前后会校验令牌和账号 UUID，若期间切换账号则放弃本地写入。
